Small practice tools I built while learning. Not production software — just things I wrote to understand how they work. Full page: [Tools](/tools/).

### [ytm-play](https://github.com/JayasuryaNair01/ytm-play)

Terminal YouTube Music client in Rust. Written to learn async networking and nested JSON parsing. Playback through `mpv`.

### [PassGuardian](https://github.com/JayasuryaNair01/PassGuardian)

Python CLI password checker: local scoring rules, optional wordlist, and a HaveIBeenPwned lookup that only sends the first 5 characters of the SHA-1 hash (k-anonymity).

### [ReconLite](https://github.com/JayasuryaNair01/ReconLite)

Multi-threaded recon CLI in Python: subdomain brute-force, directory discovery, and a basic TCP port scan. Authorized targets only.
